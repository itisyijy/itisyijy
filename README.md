## 🚀 주요 프로젝트

### [Loovi — 옥외광고 성과 측정 Vision AI](https://github.com/itisyijy/loovi-ai)

전광판 앞을 지나간 사람과 실제로 주목한 사람을 구분해 유동인구·노출·주목·주목 시간을 집계하는 팀 프로젝트입니다.

- **담당:** Vision AI 파이프라인, 추적 평가 도구, 백엔드 일부
- YOLO11 검출 → BoT-SORT 추적 → 얼굴·연령·성별 분석 → 머리 자세 기반 주목 판정을 연결하고, **5초 단위 통계를 Amazon SQS로 전송**했습니다.
- 추적 설정을 비교하는 평가 도구와 시나리오별 통계 생성 도구를 만들어 영상 분석·백엔드 적재를 검증했습니다.
- **기술:** Python · OpenCV · InsightFace · ONNX Runtime · Amazon SQS
- [백엔드](https://github.com/itisyijy/loovi-backend) · [프론트엔드](https://github.com/itisyijy/loovi-frontend) · [팀 저장소](https://github.com/Shinhan-KLLJS)

### [DELTA — 선택적 경량 테스트 시 적응](https://github.com/itisyijy/DELTA)

배포 후 데이터 분포가 바뀌는 환경에서, 시계열 예측 모델을 필요한 구간에만 적응시키는 연구입니다.

- **담당:** 제1저자, 방법 설계·구현·실험
- FedAvg로 학습한 DLinear 백본을 고정하고, **192개 파라미터의 time-affine adapter**를 클라이언트별로 갱신합니다.
- 현재 공개된 확장 실험은 **4개 데이터셋·1,350개 클라이언트**를 대상으로 하며, 적응 비율·예측 오차·지연시간을 함께 비교합니다.
- **기술:** Python · PyTorch · 연합학습 · 시계열 예측

### [MORETALE AI — 다문화 가정을 위한 이중언어 동화](https://github.com/itisyijy/MoreTale-AI)

부모와 아이가 함께 읽는 이중언어 동화에 퀴즈·음성·표지·삽화를 더하는 팀 프로젝트입니다.

- **담당:** AI 생성·검수 파이프라인과 FastAPI 서버
- 동화 생성 결과를 스키마와 검수 단계로 확인하고, 오래 걸리는 생성을 **비동기 작업 접수·상태·결과 조회 API**로 분리했습니다.
- TTS·삽화 병렬 생성, 부분 실패 처리, API 인증·요청 제한, Cloud Run 배포를 구성했습니다.
- **기술:** Python · FastAPI · Pydantic · Gemini · Google Cloud · Docker

### [Pablo — 근거와 작업 기준을 확인하는 AI 작업 도구](https://github.com/itisyijy/Pablo)

사용자의 작업 기준과 원문 근거를 기록하고, 에이전트의 행동을 확인하는 데스크톱 도구입니다.

- 논문 PDF의 인용을 쪽·원문 위치와 연결하고, 재현 조건 추출·코드와의 대조·여러 논문 비교표를 지원합니다.
- 행동 승인·경고·차단, 변경 내역 확인, 체크포인트와 되돌리기 기능을 갖추고 있습니다.
- **기술:** Python · Electron · JavaScript · PDF 텍스트 추출

### [MinDrift — 감정 대화와 AI 일기](https://github.com/itisyijy/MinDrift)

하루 동안의 감정 중심 대화를 요약해 일기로 남기는 팀 프로젝트입니다. GPT 기반 대화·일기 생성, JWT·bcrypt 인증, SQLite 저장소, 일기 조회·관리 기능을 구현했습니다.

**기술:** Next.js · React · TypeScript · Express · SQLite · GPT-4o-mini

### [Air Quality Analysis — 대기질·발전량 데이터 파이프라인](https://github.com/itisyijy/Airquality-Analysis)

대기질과 화력발전량의 수집·정제·정규화·분석을 연결한 팀 프로젝트입니다. 데이터 수집 자동화, Hadoop 클러스터와 전처리를 담당했으며, Parquet 적재·시차 상관·회귀 분석과 Streamlit 대시보드로 이어집니다.

**기술:** Python · Hadoop · Spark · Parquet · pandas · Streamlit

### [Chalkak — 카메라로 배우는 영어 단어](https://github.com/itisyijy/chalkak-app)

촬영하거나 선택한 이미지에서 객체를 인식하고 영어 단어·뜻·예문·발음 학습으로 연결하는 Android 앱입니다.

**기술:** Kotlin · TensorFlow Lite · Firebase · Room · TTS/STT

### [Depth or Width — 깊이와 너비의 효율 비교](https://github.com/itisyijy/depth_or_width)

유사한 파라미터 예산과 동일한 학습 조건에서 ResNet-110과 WRN-28-2를 CIFAR-10으로 비교했습니다. 전체 정확도뿐 아니라 클래스별 성능과 실험의 한계를 함께 정리했습니다.

**기술:** Python · PyTorch · CIFAR-10 · ResNet · Wide ResNet
