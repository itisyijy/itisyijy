### [MinDrift — 감정 대화와 AI 일기](https://github.com/itisyijy/MinDrift)

하루 동안의 감정 중심 대화를 요약해 일기로 남기는 팀 프로젝트입니다. GPT 기반 대화·일기 생성, JWT·bcrypt 인증, SQLite 저장소, 일기 조회·관리 기능을 구현했습니다.

**기술:** Next.js · React · TypeScript · Express · SQLite · GPT-4o-mini

### [Air Quality Analysis — 대기질·발전량 데이터 파이프라인](https://github.com/itisyijy/Airquality-Analysis)

대기질과 화력발전량의 수집·정제·정규화·분석을 연결한 팀 프로젝트입니다. 데이터 수집 자동화, Hadoop 클러스터와 전처리를 담당했으며, Parquet 적재·시차 상관·회귀 분석과 Streamlit 대시보드로 이어집니다.

**기술:** Python · Hadoop · Spark · Parquet · pandas · Streamlit

### [Chalkak — 카메라로 배우는 영어 단어](https://github.com/itisyijy/chalkak-app)

촬영하거나 선택한 이미지에서 객체를 인식하고 영어 단어·뜻·예문·발음 학습으로 연결하는 Android 앱입니다.

**기술:** Kotlin · TensorFlow Lite · Firebase · Room · TTS/STT

### [Depth or Width — 깊이와 너비의 효율 비교](https://github.com/itisyijy/depth_or_width)

유사한 파라미터 예산과 동일한 학습 조건에서 ResNet-110과 WRN-28-2를 CIFAR-10으로 비교했습니다. 전체 정확도뿐 아니라 클래스별 성능과 실험의 한계를 함께 정리했습니다.

**기술:** Python · PyTorch · CIFAR-10 · ResNet · Wide ResNet
